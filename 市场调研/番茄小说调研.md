## 🔥 一、平台核心机制（先搞懂规则）

番茄小说本质是**广告分成模式**，不是付费阅读。平台用广告收入养作者，所以：
- **平台最看重的是追读率**（有多少人从第一章读到最新章）
- **算法是你的第一位读者**，它根据完读率决定是否给你推流量
- 你写的是**流量产品**，不是纯文学作品

### 关键数据门槛
| 指标 | 标准 | 影响 |
|------|------|------|
| 签约门槛 | 2万字即可申请 | 进入算法推荐池 |
| 前三章完读率 | 需高于50% | 低于则被系统放弃推荐 |
| 全勤（普通）| 日更4000字 | 600元/月保底 |
| 全勤（进阶）| 日更6000字 | 800元/月保底 |
| 作者分成 | 听读收益55%、礼物70% | 基础稿费来源 |
| 短剧版权奖励 | 现象级 50万~300万 | 最大变现渠道 |

> ⚠️ 现实：约90%新人月收入0~500元，只有约1.5%的作者能月入过万。
> 但短剧改编是"杠杆"——哪怕不是顶流，被选中改编也能带来几万到几十万的额外收益。

## 🎯 三、各题材深度分析

### 1. 悬疑/副本/脑洞类 ⭐⭐⭐⭐⭐ 【最强风口】

- **当前热度**：🔥🔥🔥🔥🔥 顶流
- **代表作**：《十日终焉》《诡舍》《北派盗墓笔记》
- **读者画像**：18-30岁，男女均衡，喜欢解谜、刺激感
- **核心爽点**：规则博弈 + 绝境生存 + 智力碾压 + 每章必须有反转
- **开头公式**：`主角被困陌生场景 → 死亡规则降临 → 博弈求生 → 第一次反杀`
- **竞争程度**：中等（需要有独特设定，不能套路）
- **短剧适配性**：⭐⭐⭐⭐（强冲突，易改编）
- **新手难度**：较高（需要设计严密的规则体系）

---

### 2. 都市高武/系统/异能类 ⭐⭐⭐⭐⭐ 【最稳赛道】

- **当前热度**：🔥🔥🔥🔥🔥 常青
- **代表作**：《我在精神病院学斩神》《游戏入侵》
- **读者画像**：15-35岁，以男性为主，有打游戏习惯
- **核心爽点**：金手指觉醒 + 打脸逆袭 + 升级碾压
- **开头公式**：`主角处于最低谷(被退婚/被欺辱) → 系统/异能觉醒 → 前3章完成第一次爽点打脸`
- **竞争程度**：极高（同质化严重，必须有创新点）
- **短剧适配性**：⭐⭐⭐⭐⭐（节奏天然契合）
- **新手难度**：中等（模板清晰，但差异化难）
- **破局关键**：将系统与非常规场景结合（精神病院、养老院、幼儿园等反差感极强的地方）

---

### 3. 末世/灾难/囤货类 ⭐⭐⭐⭐ 【2025年新风口】

- **当前热度**：🔥🔥🔥🔥 上升中
- **代表作**：《我给末世主角们发编制》《末世盘古：双界仙朝》《丧尸的徒步旅行日记》
- **读者画像**：20-35岁，男女均有，安全感缺失的现代人
- **核心爽点**：囤物资爽感 + 绝境求生 + 秩序重建 + 情绪代偿（现实压力转移）
- **2025特点**：末世文出现"治愈化"趋势（《丧尸徒步旅行》），不只是硬核求生
- **竞争程度**：中等偏低（新风口，红利期）
- **短剧适配性**：⭐⭐⭐⭐（画面感强）
- **新手难度**：中低（设定相对固定，重在创意点）

---

### 4. 大女主/无CP类 ⭐⭐⭐⭐ 【女频黑马】

- **当前热度**：🔥🔥🔥🔥 快速增长
- **代表作**：《游戏入侵：抢男女主机缘会上瘾诶》
- **读者画像**：18-35岁女性，独立意识强，厌倦恋爱脑
- **核心爽点**：女主专注事业/升级，不为男人折腰，打脸所有看不起她的人
- **趋势**：去恋爱脑化，读者越来越不喜欢为了男人放弃自我的女主
- **竞争程度**：中等（赛道新，竞品少）
- **新手难度**：中等

---

### 5. 古言/年代/穿越类 ⭐⭐⭐ 【短剧改编金矿】

- **代表作**：《何不同舟渡》《主母爱谁当！纨绔夫君为我挣诰命》
- **核心爽点**：重生逆袭 + 宅斗/庭斗 + 甜虐爱情
- **短剧适配性**：⭐⭐⭐⭐⭐（女频短剧最高票仓）
- **注意**：竞争极为激烈，同质化严重，需要强差异化

## 💡 四、2025-2026年最重要的趋势

### 趋势1：短剧化思维是核心
番茄和红果短剧（字节系）高度打通。被短剧选中 = 收益翻十倍以上。
**什么样的书容易被选中**：
- 节奏极快（一分钟一冲突，三分钟一反转）
- 人设反差鲜明（废柴→无敌，卑微→霸气）
- 情绪张力强（读者能被激怒、感动、爽到）
- 场景少，对话多，视觉化强

### 趋势2：反套路 + 熟悉感
- 读者既喜欢熟悉的爽点，又渴望新奇感
- 公式：**熟悉题材 × 反套路设定** = 爆款潜力
- 例：精神病院 × 斩神 = 《斩神》；末世 × 喜剧治愈 = 《丧尸徒步旅行》

### 趋势3：情绪代偿
读者在现实中压力大，来网文寻求情绪出口：
- 打工人 → 看主角爽翻上司
- 被人看不起 → 看主角逆袭打脸
- 对世界失控感 → 看主角掌握秘密、系统无敌

### 趋势4：AIGC短剧新赛道（2026年新增）
平台对"鲜明人设+视觉化"的剧本有额外激励，未来趋势。

## 🏁 五、开头黄金公式（核心中的核心）

```
第1章：主角在最低谷 + 触发金手指/关键事件 + 悬念钩子
第2章：利用新能力解决第一个危机 + 爽点释放 + 新悬念
第3章：确立主角目标/世界观 + 更大的威胁来临 + 强钩子结尾
```

> 前三章完读率决定一切。必须让人一口气读完。

**常见钩子类型**：
- 场景钩子：把主角扔进从未见过的危险场景
- 规则钩子：建立一套读者想搞清楚的规则
- 身份钩子：主角有被隐藏的秘密身份
- 反差钩子：外表废柴，内有乾坤

## ✅ 六、调研结论与选题建议

### 综合评分（适合新手写作）

| 题材 | 市场热度 | 新手难度 | 短剧潜力 | 综合推荐 |
|------|---------|---------|---------|---------|
| 都市高武/系统（反套路） | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 🥇 强烈推荐 |
| 末世/囤货（治愈向）| ⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ | 🥈 推荐 |
| 悬疑/副本/脑洞 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 🥈 推荐（需设定功底） |
| 大女主/无CP | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | 🥉 可考虑 |
| 古言/年代穿越 | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 竞争太激烈 |
| 传统玄幻 | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | 同质化严重，不推荐 |

### 🎯 最终建议方向

**主推方向：都市高武/系统流 × 强反差场景**

理由：
1. 市场最大，读者基础最广
2. 有成熟模板，新手上手快
3. 短剧改编潜力最高（字节重点扶持方向）
4. 差异化空间大：场景选择有创意就能突围

**差异化关键**：不要选"学校""公司"等烂大街场景，找一个反差极大的场景（参考：精神病院、养老院、孤儿院、监狱、太平间……主角在这种地方觉醒系统，读者自然好奇）
