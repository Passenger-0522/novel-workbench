## 🚀 快速开始

1. 先看 [市场调研](./市场调研/番茄小说调研.md) 确定题材
2. 在 [立项](./立项/选题决策.md) 中做最终决策
3. 搭建 [世界观](./世界观/) 和 [人物](./人物/)
4. 写 [主线大纲](./大纲/主线大纲.md)，拆解各卷
5. 开始写 [正文](./正文/)

## 📝 Git 工作流

```bash
# 每次写作后提交
git add .
git commit -m "feat: 完成第X章"
git push

# 常用提交前缀
# feat:   新增内容（章节、设定）
# update: 修改完善
# fix:    修正错误
# note:   添加笔记灵感
```
